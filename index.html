🚀 SIMPLE OS v0.1

A simple command-line operating system written in Python by Karam from T STUDIO.

📥 Download SIMPLE OS:
📁 simple_os.py

📖 How to Run SIMPLE OS

Step 1: Make sure you have Python installed on your computer.
Step 2: Download the simple_os.py file from the link above.
Step 3: Place the file anywhere on your computer (Desktop, Downloads, etc.).
Step 4: Open your terminal (Command Prompt on Windows / Terminal on Linux/macOS).
Step 5: Navigate to the folder where you saved the file using the cd command.
Step 6: Run the following command:
python3 simple_os.py
🎮 Available commands inside SIMPLE OS:
help - Show available commands
info - About SIMPLE OS
neofetch - Show system info
exit - Close SIMPLE OS
⚠️ Note: SIMPLE OS runs only in the terminal. Make sure Python 3 is installed correctly.
