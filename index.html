The OS.SYS Legacy

OS.SYS was a real operating system written in Zent Coding, a custom language created by Karam Al-Bari. It featured:

  • K{W.L.U} kernel (combining ideas from Windows, Linux, Unix).
  • Graphical user interface (GUI) with black and blue colors.
  • Advanced security and self‑defense mechanisms (Zero Error, H.BOCK).
  • Strict protection system (safe.os.syst).

Due to its power, OS.SYS was voluntarily removed to maintain security. SIMPLE OS is a lightweight, open‑source version inspired by it, written entirely in Python.

How to Run

1. Ensure Python 3 is installed on your system.
2. Download simple_os.py using the button above.
3. Open a terminal in the download folder and run:
python3 simple_os.py

Available Commands (v0.2)

help — Show this help menu
info — Display version and author info
neofetch — Show logo and system information
calc — Simple calculator mode
clear — Clear the terminal screen
exit — Exit SIMPLE OS
